title: Der Zugangscode steht jetzt im Spiel
---

Manche Anlagen, wie Padel Ten, schicken nach der Buchung einen Code für die Tür. Wer gebucht hat, kann ihn beim Tippen auf „Gebucht“ gleich eintragen, oder später im Spiel mit „Code eintragen“.

Alle, die mitspielen, und die Ersatzleute sehen den Code dann groß oben im Spiel und können ihn kopieren. Wird er eingetragen oder geändert, bekommt ihr eine Mitteilung.
